# Каталог фильмов

Консольное приложение на C# для ведения личного каталога фильмов. Позволяет добавлять фильмы, выставлять оценки, искать записи и получать статистику. Каталог хранится в памяти и сохраняется в JSON-файл по команде пользователя.

## Возможности

| Пункт меню | Действие |
| --- | --- |
| `1` | Добавить фильм |
| `2` | Показать все фильмы |
| `3` | Удалить фильм по ID |
| `4` | Поставить или изменить оценку по ID |
| `5` | Найти фильмы по названию или режиссёру |
| `6` | Найти фильмы по жанру |
| `7` | Показать топ-5 фильмов по убыванию рейтинга |
| `8` | Показать средний рейтинг по каждому жанру |
| `9` | Сохранить каталог в файл |
| `10` | Загрузить каталог из файла |
| `0` | Выйти из приложения |

Поиск по названию, режиссёру и жанру работает по части строки без учёта регистра. Топ-5 формируется по всему каталогу. При расчёте среднего рейтинга жанры группируются по точному написанию, поэтому лучше вводить их единообразно.

## Технологии

- **C# и .NET 10** — консольное приложение.
- **`List<Movie>`** — хранение каталога в памяти.
- **LINQ** — поиск, сортировка и расчёт статистики.
- **`System.Text.Json`** — сохранение и загрузка JSON.

Сторонние NuGet-пакеты не используются.

## Запуск

Для сборки нужен **.NET 10 SDK**. Выполняйте команды из корневой папки проекта, где находится `catalog-movies-console.csproj`.

1. Проверьте установленный SDK и соберите приложение:

   ```sh
   dotnet --version
   dotnet build
   ```

2. Подготовьте файл каталога. При первом запуске можно создать пустой каталог — JSON-массив `[]`. Следующие команды создают файл только в том случае, если его ещё нет.

   **macOS / Linux:**

   ```sh
   if [ ! -f bin/Debug/net10.0/movies.json ]; then
     printf '[]\n' > bin/Debug/net10.0/movies.json
   fi
   ```

   **Windows (PowerShell):**

   ```powershell
   if (!(Test-Path "bin/Debug/net10.0/movies.json")) {
       Set-Content -Path "bin/Debug/net10.0/movies.json" -Value "[]" -Encoding utf8
   }
   ```

3. Запустите приложение:

   ```sh
   dotnet run --no-build
   ```

При успешном запуске приложение сообщит количество загруженных фильмов и покажет меню. Вводите номер действия и следуйте подсказкам.

### Пример работы

1. Выберите `1` и добавьте фильм: «Начало», режиссёр — «Кристофер Нолан», жанр — «Фантастика», год — `2010`.
2. Выберите `2`, чтобы посмотреть каталог и узнать ID фильма.
3. Выберите `4`, введите ID и оценку, например `9`.
4. Выберите `7` для просмотра лучших фильмов или `8` для статистики по жанрам.
5. Сохраните изменения пунктом `9`, затем выйдите через `0`.

## Данные фильма

| Поле | Тип | Описание |
| --- | --- | --- |
| `Id` | `int` | Положительный уникальный идентификатор; при добавлении назначается автоматически |
| `Title` | `string` | Название фильма, обязательно для заполнения |
| `Director` | `string` | Режиссёр, обязательно для заполнения |
| `Year` | `int` | Год выпуска от 1900 до 2025 включительно |
| `Genre` | `string` | Жанр, обязательно для заполнения |
| `Rating` | `double` | Оценка от 0 до 10 включительно; у нового фильма — `0` |

В текущей реализации верхняя граница года фиксирована: `2025`. Фильмы с оценкой `0` также участвуют в статистике. При вводе дробной оценки разделитель зависит от региональных настроек системы: например, `8,5` или `8.5`.

## Хранение каталога

Приложение использует файл `movies.json` в каталоге сборки (`AppContext.BaseDirectory`). При обычной Debug-сборке это `bin/Debug/net10.0/movies.json`, при Release-сборке — `bin/Release/net10.0/movies.json`.

- При запуске каталог загружается автоматически. Если файл отсутствует, содержит некорректный JSON или не проходит проверку данных, приложение сообщает об ошибке и завершает работу.
- Пункт `9` записывает весь текущий каталог в файл, перезаписывая его содержимое.
- Пункт `10` заменяет каталог в памяти данными из файла. Если есть несохранённые изменения, загрузка блокируется до сохранения через пункт `9`.
- При выходе через `0` автоматического сохранения нет. Перед выходом сохраните изменения вручную.

Пример содержимого `movies.json`:

```json
[
  {
    "Id": 1,
    "Title": "Начало",
    "Director": "Кристофер Нолан",
    "Year": 2010,
    "Genre": "Фантастика",
    "Rating": 8.8
  }
]
```

Для пустого каталога используйте `[]`. В JSON дробная часть числа всегда отделяется точкой. При ручном редактировании соблюдайте ограничения полей и уникальность ID.

Поскольку файл находится внутри `bin`, перед удалением папки сборки сохраните копию каталога.

## Структура проекта

```text
catalog-movies-console/
├── model/
│   └── Movie.cs               # Модель фильма
├── repository/
│   └── MovieRepository.cs     # Коллекция фильмов и работа с JSON
├── service/
│   └── MovieService.cs        # Проверки данных, поиск и статистика
├── presentation/
│   └── MovieConsole.cs        # Консольный ввод и вывод
├── Program.cs                # Создание компонентов и цикл меню
├── catalog-movies-console.csproj
├── catalog-movies-console.sln
└── README.md
```

Приложение организовано по слоям: `presentation → service → repository`. Модель `Movie` описывает данные фильма, а `Program.cs` связывает компоненты и обрабатывает выбор пункта меню.
